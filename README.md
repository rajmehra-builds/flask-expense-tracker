Expense Tracker

A web-based Expense Tracker built using Flask and SQLite that allows users to securely manage their personal expenses.

Features

- User Signup and Login
- Secure Password Hashing
- Session-Based Authentication
- Add Expenses
- Edit Expenses
- Delete Expenses
- Search Expenses by Category
- Dashboard Statistics
- Responsive Dark Theme UI
- Template Inheritance using Flask

Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
